欢迎来到我的博客！这是使用 **Hexo** + **Volantis** 主题发布的第一篇文章。

## 快速开始

### 新建一篇文章

``` bash
$ hexo new "我的新文章"
```

### 启动本地预览

``` bash
$ hexo server
```

### 生成静态文件

``` bash
$ hexo generate
```

### 部署到远程

``` bash
$ hexo deploy
```
